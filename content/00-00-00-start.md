# 00-00-00 – Start

Dies ist ein Testartikel für den neuen AustroTopia-Workflow. Der Inhalt dient ausschließlich dazu, die technische Kette von Git über den Website-Build bis zur statischen Veröffentlichung zu prüfen.

Der spätere Aufbau kann beliebig erweitert werden. Entscheidend ist zunächst nur, dass der Inhalt als einfache Markdown-Datei im Repository liegt und daraus automatisch eine lesbare Webseite erzeugt werden kann.
